# Servidor - HTTP y FTP

## Descripción
Este proyecto consiste en un servidor auxiliar desarrollado en Python que levanta servicios para la gestión y transferencia de archivos.

El sistema cuenta con:

- Un servidor HTTP ejecutándose en el puerto 8080
  - Permite visualizar una página de Inicio
  - Lista los archivos disponibles
  - Permite descargar archivos desde el navegador

- Un servidor FTP ejecutándose en el puerto 2121
  - Se encarga de enviar los archivos al cliente
  - Permite la transferencia de archivos mediante el protocolo FTP
